# chat-traductor

Chat con traducción automática español ↔ búlgaro. PWA instalable.

- **Stack**: React + Vite (este repo contiene el bundle compilado), Supabase (mensajes en tiempo real).
- **Publicado en**: https://josulo72.github.io/chat-traductor/
- **Origen**: extraído de `big-agents-studio/chat/` con su historial.

Este repositorio es el artefacto de despliegue (build de producción); el código fuente no está versionado aquí.
